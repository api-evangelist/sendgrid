# SendGrid

> SendGrid (a Twilio company) is a cloud-based email delivery platform providing reliable transactional and marketing email over an HTTP v3 REST API and SMTP relay. This llms.txt was GENERATED by the API Evangelist enrichment pipeline from the SendGrid catalog (apis.yml) and the artifacts in this repository, as a SendGrid-scoped index. All APIs authenticate with a bearer API key against https://api.sendgrid.com (EU data residency host: https://api.eu.sendgrid.com).

## APIs
- [Mail Send v3 API](https://www.twilio.com/docs/sendgrid/api-reference/mail-send): Send transactional email at scale over HTTP.
- [Marketing Campaigns Contacts API](https://www.twilio.com/docs/sendgrid/api-reference/contacts): Manage marketing contacts, imports, exports, and search.
- [Marketing Campaigns Lists API](https://www.twilio.com/docs/sendgrid/api-reference/lists): Manage static contact lists.
- [Marketing Campaigns Segments 2.0 API](https://www.twilio.com/docs/sendgrid/api-reference/segmenting-contacts-v2): Dynamic audience segments.
- [Marketing Campaigns Single Sends API](https://www.twilio.com/docs/sendgrid/api-reference/single-sends): One-time marketing email sends.
- [Transactional Templates API](https://www.twilio.com/docs/sendgrid/api-reference/transactional-templates): Manage dynamic email templates and versions.
- [Suppressions API](https://www.twilio.com/docs/sendgrid/api-reference/suppressions-unsubscribe-groups): Manage bounces, blocks, spam reports, and unsubscribe groups.
- [Email Activity API](https://www.twilio.com/docs/sendgrid/api-reference/email-activity): Query stored message activity.
- [Email Address Validation API](https://www.twilio.com/docs/sendgrid/api-reference/email-address-validation): Real-time email address validity (Pro/Premier).
- [Statistics API](https://www.twilio.com/docs/sendgrid/api-reference/stats): Aggregated email program statistics.
- [Domain Authentication API](https://www.twilio.com/docs/sendgrid/api-reference/domain-authentication): SPF/DKIM sender domain authentication.
- [API Keys API](https://www.twilio.com/docs/sendgrid/api-reference/api-keys): Manage API keys and their scopes.
- [Subusers API](https://www.twilio.com/docs/sendgrid/api-reference/subusers-api): Multi-tenant sub-account management.
- [Webhooks Configuration API](https://www.twilio.com/docs/sendgrid/api-reference/webhooks): Event and Inbound Parse webhooks.
